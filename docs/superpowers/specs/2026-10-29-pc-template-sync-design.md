# PC 新建报送模板同步设计

## 目标

将 H5 的四个上报模板、模板专属字段、切换行为和提交阻断规则同步到 V8 审核上报 PC 端“新建报送”弹窗。

PC 端保留自身桌面表单布局与公共字段，模板专属字段使用 PC 控件样式渲染。

## 范围

- 同步四个模板：突发事件速报、民生诉求核查、网络谣言线索、专项风险线索。
- 同步每个模板的字段配置、必填属性、选项、链接、附件和静态提示。
- 同步模板切换时扩展字段的重置行为。
- 同步提交前的扩展字段校验。
- 同步各模板的审核人缺失阻断规则。
- 保存模板 ID 和字段值快照，支持编辑回填。

不在本次范围内：

- 改造 PC 审核流转引擎。
- 与 H5 应用建立运行时跨应用引用。
- 修改 PC 公共字段的数据结构。

## 实现方式

采用 PC 本地适配方案：

1. 在 PC 端复制四个模板的字段定义，保持模板 ID、顺序、名称和字段配置与 H5 一致。
2. 在 PC 端新增桌面版模板字段渲染器。
3. 不跨目录导入 H5 组件，避免破坏两个独立应用的构建边界。

这不是运行时共享代码，但可以避免重构两个应用的构建入口。模板定义修改时需要同步检查两端。

## 数据模型

扩展 `NewReportFormData`：

```ts
interface NewReportFormData {
  // 现有公共字段
  templateId?: string;
  templateName?: string;
  templateFieldValues?: Record<string, TemplateFieldValue>;
}
```

扩展 `ReportItem`：

```ts
interface ReportItem {
  // 现有字段
  templateFieldValues?: Record<string, TemplateFieldValue>;
}
```

模板字段类型与 H5 保持一致：

- 数字
- 日期
- 单选框组
- 多选框组
- 下拉单选
- 下拉多选
- 链接
- 附件
- 静态文本提示

附件字段复用 PC 现有的 `attachments: Attachment[]` 状态，不再增加第二个上传区域。

## 组件结构

### PCTemplateExtraFields

职责：

- 根据当前模板配置渲染桌面端字段。
- 接收字段值、错误状态和变更回调。
- 渲染链接截图预览、重截和删除操作。
- 管理下拉多选交互。
- 代理附件字段到 PC 现有附件上传区域。
- 渲染静态文本提示。

该组件不负责提交、公共字段和审核人判断。

### NewReportModal

职责：

- 维护当前模板、模板扩展值和错误状态。
- 切换模板时刷新扩展字段并保留公共字段。
- 合并公共字段与扩展字段的提交校验。
- 在扩展字段校验通过后执行审核人阻断校验。
- 提交时写入模板 ID、模板名称和字段值快照。

### PC 审核人阻断校验

新增 PC 本地校验模块，规则与 H5 一致：

| 模板 | 规则 |
| --- | --- |
| 突发事件速报模板 | 不执行审核人缺失阻断 |
| 民生诉求核查模板 | 终审审核人缺失时阻断 |
| 网络谣言线索模板 | 维持当前判断 |
| 专项风险线索模板 | 组织节点审核人和终审审核人同时缺失时联合阻断 |

阻断弹窗标题统一为“暂时无法提交”，正文沿用 H5 对应场景文案。

## 表单顺序

PC 现有公共字段保持原有顺序和桌面布局。模板专属字段插入在“建议处置举措”之后、附件区域之前。

模板选择位于弹窗顶部，仅在新建模式下展示。编辑模式根据 `editingReport.templateId` 自动恢复对应模板，并显示模板字段。

## 模板字段组合

### 突发事件速报模板

- 数字：现场涉及人数。
- 日期：事件发生日期。
- 单选框组：事件紧急等级。
- 多选框组：信息传播渠道。
- 下拉单选：主要责任部门。
- 下拉多选：需要联动处置的单位。
- 链接：权威信息或现场来源链接。
- 附录：复用现有附件区。
- 静态文本提示：确保时间、地点、事实和材料准确。

该模板包含全部控件类型，不执行审核人阻断。

### 民生诉求核查模板

- 日期。
- 单选框组：诉求紧急程度。
- 多选框组：群众反映渠道。
- 下拉单选：牵头办理部门。
- 附录：复用现有附件区。
- 静态文本提示：区分个人诉求与共性民生问题。

### 网络谣言线索模板

- 日期。
- 多选框组：传播平台。
- 下拉多选：证据材料类型。
- 链接：谣言原文或传播页面。
- 附录：复用现有附件区。
- 静态提示：保留原始链接、传播账号和取证时间。

### 专项风险线索模板

- 数字：涉及对象或场所数量。
- 日期：风险发现日期。
- 单选框组：风险等级。
- 下拉单选：风险类别。
- 链接：风险来源或佐证链接。
- 附录：复用现有附件区。
- 静态提示：同步组织节点审核和终审。

## 状态与校验

- 新建默认选中“突发事件速报模板”。
- 切换模板时只重置模板扩展字段，不重置 PC 公共字段。
- 必填字段为空时阻止提交，并聚焦第一个错误字段。
- 链接非空但格式错误时阻止提交。
- 下拉多选最多显示 3 个名称，其余显示 `+N`。
- 附件限制为图片和常见文档，排除视频。
- 扩展字段校验通过后才执行审核人阻断校验。
- 审核人阻断时不关闭弹窗，便于用户修正或联系管理员。
- 编辑模式优先恢复已保存的字段快照；旧数据没有快照时生成完整演示回填值。

## 兼容性

- 现有公共字段、附件预览、编辑更新和提交回调保持可用。
- `initialTemplate` 仍可用于预填公共字段。
- 未识别的旧模板 ID 回退到第一个模板。
- 旧上报记录没有 `templateFieldValues` 时仍可打开编辑。

## 验证标准

- PC 新建报送弹窗显示四个 H5 同名模板。
- 第一个模板显示全部模板控件。
- 其余三个模板显示各自的字段组合。
- 切换模板后公共字段保留、扩展字段刷新。
- 必填和链接校验可阻止提交。
- 四个模板的审核人阻断结果与 H5 一致。
- 附件字段只出现一个上传区域。
- 编辑被驳回或草稿报送时能恢复模板与字段值。
- PC 生产构建通过，且本次修改不新增 TypeScript 错误。

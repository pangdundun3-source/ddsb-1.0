# 业务配置联动与规则说明

**适用对象**：开发、测试、UI  
**覆盖端**：MT 应用管理端、V8 客户管理端、审核上报 PC、审核上报 H5  
**文档口径**：以当前原型实现为准

---

## 一、模块之间的关系

1. **模板新增默认为停用状态**；启用前须校验是否已关联「打分规则」与「审核流程」。
2. **审核流程若为模式一 / 模式二**：依赖外部审核。须区分两层——**未开通**（`activatedStatus`）时配置侧硬锁启用/关联；**已开通但客户停用**（`status`）时配置不锁，仅 PC / H5 入口与模板选用拦截。**模式三（直达）不受外审门禁**。
3. **停用打分规则或审核流程**时，给出操作确认；停用后须同步处理已关联模板（**解绑并停用**）。
4. **增值业务「外部审核」客户侧停用**：**不级联**改流程 / 模板启停状态；仅关闭 PC / H5「审核管理」入口，并拦截关联外部审核流程的模板选用。MT 关闭开通态同样不解绑、不强制停用模板，但会硬锁配置侧对模式一/二的启用与关联。
5. **系统默认（`isDefault`）审核流程 / 打分规则**：全局与机构均**不支持启停**（开关置灰）；机构侧另不可编辑、删除。系统默认**模板**机构侧仅可启停。

```
打分规则 ─┐
          ├─→ 报送模板（启用条件：关联打分 + 流程；模式一/二另需已开通外审）
审核流程 ─┘
    ↑
外部审核
  · 未开通 → 配置硬锁 + PC/H5 拦截（不解绑、不强制停用）
  · 已开通但停用 → 仅 PC/H5 拦截，配置不锁
```

## 二、全局配置与机构配置

| 维度 | 全局（平台） | 机构 |
| --- | --- | --- |
| 新建流程 / 打分 / 模板 | 写入全局母版；新机构 / 空库 fallback 继承；**已落库机构副本不自动覆盖** | 可新建机构自定义项 |
| 系统默认流程 / 打分 | **不可**编辑、删除、启停 | **不可**编辑、删除、启停（置灰） |
| 系统默认模板 / 字典 | 可维护；可启停 | 仅查看内容；模板 / 字典**可启停**；不可编辑删除 |
| 个性化诉求 | 可另建全局自定义项 | 通过「新建自定义」满足 |

**备注**：

- 系统默认流程 / 打分提示：`系统默认审核流程不支持启停。如需调整，请新建自定义审核流程。`（打分同理）
- 系统默认模板：机构端仅支持启用、停用，不支持编辑和删除。
- 关联关系详版（泳道 / 判断树 / 两层外审门禁）见《业务配置关联关系说明.md》。

## 三、流程修改与打分修改的生效范围

| 配置项 | 修改后生效范围 | 说明 / 确认文案 |
| --- | --- | --- |
| **审核流程** | **不影响历史数据**；仅影响**后续新增的相关上报** | 编辑已有流程并保存时二次确认：「改动的流程只影响后续新增的相关上报，已经上报的流程不受影响。」（标题：保存确认） |
| **打分规则** | **实时同步生效** | 修改等级、分值、规则内容后，按最新规则即时生效，不区分「历史上报 / 后续上报」两套版本 |

> 说明：流程强调「版本隔离」；打分强调「实时同步」。验收时勿混为一谈。  
> 模板字段结构变更：与流程一致，不影响历史上报内容，仅作用于后续新增上报。

## 四、各模块操作规则

### A. 审核打分规则

| 操作 | 规则 |
| --- | --- |
| 新增 / 编辑保存 | 总分须 > 0；至少 2 个互斥评分等级；等级名称必填；等级分值须在 0～总分之间；**保存后实时同步** |
| 删除等级 | 至少保留 2 个得分等级 |
| 启用 | **应用端**：允许多组同时启用；**客户管理端**：同时仅允许启用一组（启用一组时其余组自动停用） |
| 停用 | 至少保留一组启用中的打分规则；若已关联模板，需确认后解绑并停用模板 |
| 删除默认项 | 机构侧禁止 |

**停用确认文案**：  
「{名称}」已关联 N 个报送模板。停用后将解绑并停用这些模板，上报端将无法选用。确定停用？

---

### B. 审核流程

| 操作 | 规则 |
| --- | --- |
| 新增 / 保存模式一、二 | **未开通**外审时不可选用该模式；**已开通但客户停用**时配置内仍可保存 |
| 启用模式一、二 | **未开通**时禁止启用；**已开通但客户停用**时配置内可启停 |
| 系统默认流程启停 | **全局与机构均禁止**（置灰） |
| 删除审批节点 | 至少保留 1 个审批节点 |
| 编辑后保存 | 二次确认：只影响后续新增相关上报，已上报流程不受影响 |
| 停用（自定义） | 若已关联模板，需确认后解绑并停用模板 |
| 删除 / 编辑默认项 | 全局与机构均禁止 |

**流程保存确认文案**：  
「改动的流程只影响后续新增的相关上报，已经上报的流程不受影响。」

**流程停用确认文案**（有关联模板时）：  
「{名称}」已关联 N 个报送模板。停用后将解绑并停用这些模板，上报端将无法选用。确定停用？

---

### C. 报送模板

| 操作 | 规则 |
| --- | --- |
| 新增保存 | **默认停用**；提示先关联打分规则与审核流程后再启用 |
| 启用（报送类型） | 须已关联打分规则与审核流程；若关联模式一/二且**未开通**外审 → 拦截启用（不解绑、不强制改停用） |
| 关联流程 | **未开通**时不可把模式一/二关联到模板；**已开通但客户停用**时配置仍可关联，上报端再按启停拦截 |
| 下拉选项 | 仅展示「启用中」的打分规则与审核流程 |
| 字段保存 | 模板名称必填、不可重名；至少 1 个表单字段；字段命名 / 选项 / 字数等按表单校验 |
| 系统默认模板 | 机构侧不可编辑、不可删除 |
| 标准模板 | 停用 / 删除前二次确认；停用态不可设为标准模板 |

**新增成功提示**：  
新增模板「{名称}」已保存，当前为停用。请关联打分规则和审核流程后再启用

**启用拦截（按缺失项）**：

| 缺失情况 | 提示 |
| --- | --- |
| 打分 + 流程均未关联 | 请先在右侧「其他业务配置」关联打分规则和审核流程并保存，再启用该模板 |
| 仅未关联打分规则 | 请先在右侧「其他业务配置」关联打分规则并保存，再启用该模板 |
| 仅未关联审核流程 | 请先在右侧「其他业务配置」关联审核流程并保存，再启用该模板 |

## 五、停用级联一览

| 触发操作 | 级联结果 |
| --- | --- |
| 客户管理端停用「外部审核」 | **不级联**；仅 PC / H5 入口与关联模板选用拦截；配置不锁 |
| MT 关闭外审开通态 | **不级联**解绑/停用；配置侧硬锁模式一/二启用与关联 |
| 停用「审核流程」（自定义） | 关联模板解绑并停用 |
| 停用「打分规则」（自定义） | 关联模板解绑并停用（且至少保留一组启用中的打分） |
| 系统默认流程 / 打分 | 不可停用，故无此级联 |

## 六、增值业务联动（摘要）

```
应用端机构开通 / 关闭
        ↓
客户管理端跟随开通态，并本地启停
        ↓
PC / H5 按启停态控制功能入口（区分「未开通」与「已停用」文案）
```

| 增值业务 | 客户侧停用 / 未开通时 | 行为 |
| --- | --- | --- |
| 外部审核 | PC / H5「审核管理」入口拦截；依赖外部审核流程的报送模板不可选用 | **未开通**：配置硬锁模式一/二；**已开通但停用**：配置内仍可编辑启停 |
| 指令流转 | 客户管理端审核记录「转办」拦截 | — |
| 批量审核 / 系统公告 / 首发重复识别 | 当前原型未做与上同等的入口级拦截 | — |

可用判定：**已开通且启用**。应用端明确关闭开通时，以未开通为准。完整拦截文案见 **第十章**。

## 七、PC / H5 新增模板上报：审核人缺失拦截

审核上报 PC、H5 在**选择模板新建上报并提交**时，若流程所需审核人未配置，拦截提交（弹窗标题：**暂时无法提交**）。完整文案见 **第十章**。

| 场景 | 说明 |
| --- | --- |
| **仅终审无审核人** | 终审节点未配置审核人 |
| **仅组织节点无审核人** | 组织节点审核人未配置 |
| **组织节点 + 终审都无审核人** | 两类审核人均未配置 |

> 说明：此处「组织节点审核」指流程中的外部组织节点审核人配置，与增值业务「外部审核」开关不是同一概念。

**原型演示模板对照（PC / H5）**：

| 模板 | 演示场景 |
| --- | --- |
| 民生诉求核查模板 | 终审无人 |
| 专项风险线索模板 | 组织节点审核人 + 终审人均无人 |
| 突发事件速报模板 | 不走上述缺失拦截演示 |

## 十、拦截提示文案（本次更新 · 口径定稿）

> 增值业务类文案须区分「未开通」与「已停用」；模板上报无审核人拦截为独立三类。

### 指令流转（审核记录「转办」）

- **未开通**：本机构尚未开通增值业务「指令流转」，因此无法发起转办。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「指令流转」，因此无法发起转办。如需使用，请联系本机构管理员在客户管理端重新启用。

### 外部审核 · 审核管理入口

- **未开通**：本机构尚未开通增值业务「外部审核」，因此无法进入审核管理。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「外部审核」，因此无法进入审核管理。如需使用，请联系本机构管理员在客户管理端重新启用。

### 外部审核 · 关联模板选用

- **未开通**：本机构尚未开通增值业务「外部审核」，该模板关联的审核流程依赖外部审核，暂时无法选用。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「外部审核」，该模板关联的审核流程依赖外部审核，暂时无法选用。如需使用，请联系本机构管理员在客户管理端重新启用。

### 模板上报 · 无审核人拦截

- **仅终审无审核人**：当前模板需要完成终审，但您所在机构还未配置终审审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。
- **仅组织节点无审核人**：当前模板需要完成组织节点审核，但您所在机构尚未配置组织节点审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。
- **组织节点 + 终审都无审核人**：当前模板需要完成组织节点审核和终审，但您所在组织节点和机构尚未配置组织节点审核人和终审人，因此暂时无法提交。请联系组织管理员补充组织节点审核人和终审审核人后再试。

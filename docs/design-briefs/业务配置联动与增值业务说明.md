# 业务配置联动与规则说明

**适用对象**：开发、测试、UI  
**覆盖端**：MT 应用管理端、V8 客户管理端、审核上报 PC、审核上报 H5  
**文档口径**：以当前原型实现为准

---

## 一、模块之间的关系

1. **模板新增默认为停用状态**；启用前须校验是否已关联「打分规则」与「审核流程」。
2. **审核流程若为模式一 / 模式二**，还需依赖增值业务「外部审核」是否处于启用状态；**模式三（直达）不依赖**。
3. **停用打分规则或审核流程**时，给出操作确认；停用后须同步处理已关联模板（**解绑并停用**）。
4. **增值业务「外部审核」停用**时，系统须同时停用模式一 / 模式二相关的流程，并解绑停用关联模板。

```
打分规则 ─┐
          ├─→ 报送模板（启用条件）
审核流程 ─┘
    ↑
外部审核（仅模式一 / 模式二）
```

## 二、全局配置与机构配置

| 维度 | 全局（平台） | 机构 |
| --- | --- | --- |
| 新建流程 / 打分 / 模板 | 作为全平台系统默认项初始化到机构 | 可新建机构自定义项 |
| 系统默认项编辑 | 可维护 | 仅查看；不可改内容 |
| 系统默认项删除 | 按平台规则维护 | 不可删除 |
| 系统默认项启停 | 可启停 | 可启停 |
| 个性化诉求 | — | 通过「新建自定义」满足 |

**备注**：全局新建的打分规则 / 审核流程 / 模板，为全平台所有机构初始化的系统默认项。机构端仅支持启用、停用，不支持编辑和删除；如需个性化，机构可另建自定义项。

## 三、流程修改与打分修改的生效范围

| 配置项 | 修改后生效范围 | 说明 / 确认文案 |
| --- | --- | --- |
| **审核流程** | **不影响历史数据**；仅影响**后续新增的相关上报** | 编辑已有流程并保存时二次确认：「改动的流程只影响后续新增的相关上报，已经上报的流程不受影响。」（标题：保存确认） |
| **打分规则** | **实时同步生效** | 修改等级、分值、规则内容后，按最新规则即时生效，不区分「历史上报 / 后续上报」两套版本 |

> 说明：流程强调「版本隔离」；打分强调「实时同步」。验收时勿混为一谈。  
> 模板字段结构变更：与流程一致，不影响历史上报内容，仅作用于后续新增上报。

## 四、各模块操作规则

### A. 审核打分规则

| 操作 | 规则 |
| --- | --- |
| 新增 / 编辑保存 | 总分须 > 0；至少 2 个互斥评分等级；等级名称必填；等级分值须在 0～总分之间；**保存后实时同步** |
| 删除等级 | 至少保留 2 个得分等级 |
| 启用 | **应用端**：允许多组同时启用；**客户管理端**：同时仅允许启用一组（启用一组时其余组自动停用） |
| 停用 | 至少保留一组启用中的打分规则；若已关联模板，需确认后解绑并停用模板 |
| 删除默认项 | 机构侧禁止 |

**停用确认文案**：  
「{名称}」已关联 N 个报送模板。停用后将解绑并停用这些模板，上报端将无法选用。确定停用？

---

### B. 审核流程

| 操作 | 规则 |
| --- | --- |
| 新增 / 保存模式一、二 | 「外部审核」未启用时禁止保存 |
| 启用模式一、二 | 「外部审核」未启用时禁止启用 |
| 删除审批节点 | 至少保留 1 个审批节点 |
| 编辑后保存 | 二次确认：只影响后续新增相关上报，已上报流程不受影响 |
| 停用 | 若已关联模板，需确认后解绑并停用模板 |
| 删除 / 编辑默认项 | 机构侧禁止删除；默认项编辑仅查看 |

**外部审核拦截文案**：  
「未开通外部审核功能，该流程所依赖的外部审核暂不可用，暂时无法启用 / 暂时无法使用。」

**流程保存确认文案**：  
「改动的流程只影响后续新增的相关上报，已经上报的流程不受影响。」

**流程停用确认文案**（有关联模板时）：  
「{名称}」已关联 N 个报送模板。停用后将解绑并停用这些模板，上报端将无法选用。确定停用？

---

### C. 报送模板

| 操作 | 规则 |
| --- | --- |
| 新增保存 | **默认停用**；提示先关联打分规则与审核流程后再启用 |
| 启用（报送类型） | ① 须已关联打分规则与审核流程；② 若关联模式一/二，须外部审核已启用 |
| 关联流程 | 外部审核未启用时，不可选择 / 关联模式一、二 |
| 下拉选项 | 仅展示「启用中」的打分规则与审核流程 |
| 字段保存 | 模板名称必填、不可重名；至少 1 个表单字段；字段命名 / 选项 / 字数等按表单校验 |
| 系统默认模板 | 机构侧不可编辑、不可删除 |
| 标准模板 | 停用 / 删除前二次确认；停用态不可设为标准模板 |

**新增成功提示**：  
新增模板「{名称}」已保存，当前为停用。请关联打分规则和审核流程后再启用

**启用拦截（按缺失项）**：

| 缺失情况 | 提示 |
| --- | --- |
| 打分 + 流程均未关联 | 请先在右侧「其他业务配置」关联打分规则和审核流程并保存，再启用该模板 |
| 仅未关联打分规则 | 请先在右侧「其他业务配置」关联打分规则并保存，再启用该模板 |
| 仅未关联审核流程 | 请先在右侧「其他业务配置」关联审核流程并保存，再启用该模板 |
| 已绑模式一/二但外部审核未开 | 未开通外部审核功能，当前模板关联的审核流程依赖外部审核，暂时无法启用。请先开通外部审核，或更换流程后再启用。 |

## 五、停用级联一览

| 触发操作 | 级联结果 |
| --- | --- |
| 停用「外部审核」 | 启用中的模式一 / 二流程同步停用；相关模板解绑并停用 |
| 停用「审核流程」 | 关联模板解绑并停用 |
| 停用「打分规则」 | 关联模板解绑并停用（且至少保留一组启用中的打分） |

**外部审核停用确认**：  
停用「外部审核」后，依赖该功能的 N 个审核流程将同步停用，并解绑且停用关联的 M 个报送模板。确定停用？

## 六、增值业务联动（摘要）

```
应用端机构开通 / 关闭
        ↓
客户管理端跟随开通态，并本地启停
        ↓
PC / H5 按启停态控制功能入口
```

| 增值业务 | 客户侧停用 / 未开通时 | 提示文案 |
| --- | --- | --- |
| 外部审核 | PC / H5「审核管理」入口拦截；本端模式一/二与相关模板级联 | 审核管理属于增值业务「外部审核」，暂未开通或已停用，请先联系相关人员开通后使用。 |
| 指令流转 | 客户管理端「转办」拦截 | 转办属于增值业务「指令流转」，暂未开通或已停用，请先联系相关人员开通后使用。 |
| 批量审核 / 系统公告 / 首发重复识别 | 当前原型未做与上同等的入口级拦截 | — |

可用判定：**已开通且启用**。应用端明确关闭开通时，以未开通为准。

## 七、PC / H5 新增模板上报：审核人缺失拦截

审核上报 PC、H5 在**选择模板新建上报并提交**时，若流程所需审核人未配置，拦截提交（弹窗标题：**暂时无法提交**）。

| 场景 | 拦截提示 |
| --- | --- |
| **仅终审没人** | 当前模板需要完成终审，但您所在机构还未配置终审审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。 |
| **组织节点审核人 + 终审人都没人** | 当前模板需要完成组织节点审核和终审，但您所在组织节点和机构尚未配置组织节点审核人和终审人，因此暂时无法提交。请联系组织管理员补充组织节点审核人和终审审核人后再试。 |
| **仅组织节点审核人没人** | 当前模板需要完成组织节点审核，但您所在机构尚未配置组织节点审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。 |

> 说明：此处「组织节点审核」指流程中的外部组织节点审核人配置，与增值业务「外部审核」开关不是同一概念；但模式一 / 二启用仍受增值业务「外部审核」约束（见第一章）。

**原型演示模板对照（PC / H5）**：

| 模板 | 演示场景 |
| --- | --- |
| 民生诉求核查模板 | 终审无人 |
| 专项风险线索模板 | 组织节点审核人 + 终审人均无人 |
| 突发事件速报模板 | 不走上述缺失拦截演示 |

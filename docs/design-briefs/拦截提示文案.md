# 拦截提示文案（口径定稿）

> 摘自《业务配置联动与规则说明》第十章。增值业务类文案区分「未开通」与「已停用」。

## 指令流转（审核记录「转办」）

- **未开通**：本机构尚未开通增值业务「指令流转」，因此无法发起转办。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「指令流转」，因此无法发起转办。如需使用，请联系本机构管理员在客户管理端重新启用。

## 外部审核 · 审核管理入口

- **未开通**：本机构尚未开通增值业务「外部审核」，因此无法进入审核管理。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「外部审核」，因此无法进入审核管理。如需使用，请联系本机构管理员在客户管理端重新启用。

## 外部审核 · 关联模板选用

- **未开通**：本机构尚未开通增值业务「外部审核」，该模板关联的审核流程依赖外部审核，暂时无法选用。如需使用，请联系平台相关人员开通。
- **已停用**：本机构已停用增值业务「外部审核」，该模板关联的审核流程依赖外部审核，暂时无法选用。如需使用，请联系本机构管理员在客户管理端重新启用。

## 模板上报 · 无审核人拦截

- **仅终审无审核人**：当前模板需要完成终审，但您所在机构还未配置终审审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。
- **仅组织节点无审核人**：当前模板需要完成组织节点审核，但您所在机构尚未配置组织节点审核人，因此暂时无法提交。请联系组织管理员补充审核人后再试。
- **组织节点 + 终审都无审核人**：当前模板需要完成组织节点审核和终审，但您所在组织节点和机构尚未配置组织节点审核人和终审人，因此暂时无法提交。请联系组织管理员补充组织节点审核人和终审审核人后再试。

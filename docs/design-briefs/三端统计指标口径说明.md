# 三端统计指标口径说明（开发交接）

> **口径来源**：以现有原型代码可推断规则为准（方案 A）。无法从代码确认的标 **「待产品确认」**。  
> **范围**：客户管理端、审核上报 PC、审核上报 H5；模块覆盖首页、报送统计、审核统计、统计管理、考核管理（本端无则标注）。  
> **配套 Excel**：同目录 `三端统计指标口径说明.xlsx`。  
> **生成日期**：2026-11-13

## 0. 阅读约定

| 字段 | 含义 |
| --- | --- |
| 数据来源 | `reports计算` = 从报送列表实时聚合；`种子趋势` = `buildTrendSeries` 伪随机；`硬编码mock` = 字面量；`生成表` = 模板/种子生成排行 |
| 时间窗 | **存量** = 不过滤日期；**近7日** = 以数据最新日期为锚的滚动 7 天（多数非日历「今天」）；**用户周期** = 页面日期控件 |
| 状态别名 | 客户/PC 多用中文 `auditStatus`；H5 多用英文 `ReportStatus`（见 §0.2） |

### 0.1 跨端模块有无

| 模块 | 客户管理端 | 审核上报 PC | 审核上报 H5 |
| --- | --- | --- | --- |
| 首页 | `#/home` | `#/home` | Tab「首页」（无 KPI） |
| 报送统计 | 无独立页；工作台 `#/report-summary` KPI | `#/report-statistics` + `#/report-summary` KPI | 报送 Tab 顶栏 KPI |
| 审核统计 | `#/audit-statistics` | `#/audit-statistics` | 审核 Tab 顶栏 KPI |
| 统计管理 | `#/statistics` | **本端无** | **本端无**（「我的」内有个人统计） |
| 考核管理 | `#/evaluation` | **本端无** | **本端无** |
| 其它统计入口 | `#/report-audit` 审核 Banner | `#/report-audit`；PC 内嵌 `H5MobilePortal` 统计面板 | 「我的」统计 |

### 0.2 状态映射（H5 ↔ 客户/PC）

| H5 `status` | 客户/PC `auditStatus`（常见） |
| --- | --- |
| `pending_audit` | 待审核 |
| `auditing` | 审核中 |
| `approved` | 已采纳 / 已通过 |
| `rejected` | 被驳回 / 已驳回 |
| `pending_transfer` / `transferred` | 待转办 / 已转办 |
| `draft` | 草稿 |

### 0.3 共用种子趋势（`statsTrend.ts` / 统计管理内副本）

每时间桶（日/周/月/季/年）生成一行，**非真实报送聚合**：

| 字段 | 单位 | 计算规则（代码） |
| --- | --- | --- |
| 累计报送量 `total` | 件 | `dailyBase≈1380+…`，再 × 跨度天数 × `(0.92~1.08)` |
| 累计采纳量 `passed` | 件 | `round(total × passRate / 100)` |
| 驳回整改量 `rejected` | 件 | `round(total × (0.05~0.09))` |
| 首审直通率 `directRate` | % | `74 + 随机浮动`（**待产品确认**：非真实直通定义） |
| 整体采纳率 `passRate` | % | `min(99, directRate+10+随机)` |
| 审核处理率 `processRate` | % | `95 + 随机` |
| 转办闭环率 `closedRate` | % | `91 + 随机` |
| 平均审核耗时 `avgTime` | 分钟 | `12.5 + 随机` |
| 累计处理 `audited` | 次 | `max(passed, round(total×0.9~0.98))` |

## 图 1 · 跨端泳道

母版维护 → 机构继承 → 自定义项 → 运行时门禁。四条泳道自上而下＝全局 MT → 机构 MT → V8 客户管理端 → PC/H5；横向左→右为时间顺序。

| 步 | 泳道 | 行为 |
| --- | --- | --- |
| 1 | 全局 | 维护母版：模板 / 流程 / 打分 / 字典 / 增值业务目录。系统默认流程与打分不可启停、编辑、删除；模板与字典可启停；自定义项可增删改启停 |
| 2 | 全局 → 机构 | 新机构开通 / 空库首次进入：fallback 读母版并生成机构副本（只读复制；不回写母版） |
| 3 | 机构 | 继承项（`isDefault`）：模板可启停、不可编辑删除；流程 / 打分不可启停；绑定锁定 |
| 4 | 机构 | 新建自定义模板 / 流程 / 打分：可增删改、可启停；绑定只作用于本机构 |
| 5 | 机构 | 开通 / 关闭「外部审核」开通态（`activatedStatus`）。未开通 → 配置侧硬锁模式一 / 二（不解绑、不强制停用模板） |
| 6 | 客户管理端 | 与机构同源展示；继承规则同左；可本地启停已开通的增值业务（`status`） |
| 7 | 客户管理端 | 发布 `ddsb_va_client`；MT 发布开通态 `ddsb_va_prov` |
| 8 | PC / H5 | 选模板上报、进审核管理：`usable = 已开通 ∧ 启用`；依赖外审的模板在不可用时拦截 |

### 继承项 vs 自定义项

| | 报送模板 | 审核流程 | 打分规则 |
| --- | --- | --- | --- |
| 继承项 | 不可编辑删除；可启停；绑定锁定 | 不可编辑删除；不可启停 | 不可编辑删除；不可启停 |
| 自定义项 | 可增删改启停；可配绑定 | 可增删改启停；停用按级联 | 可增删改启停；至少保留 1 组启用；V8 客户端同时仅一组启用 |

全局侧：系统默认流程 / 打分同样不可启停 / 编辑 / 删除；系统默认模板 / 字典可启停。

### 母版变更 → 已有机构

| 变更 | 已落库机构副本 | 新机构 / 空库 |
| --- | --- | --- |
| 模板 / 流程 / 打分 | 不自动覆盖 | fallback 最新母版 |
| 增值业务名称 / 描述 | 会同步 | 跟随 |
| 固定字段规则 | 可更新全局 + 机构 `isDefault` 模板字段 | 跟随 |
| 「同步到已创建机构」 | 当前无此能力 | — |

### 运行时不放行（PC / H5）

- 审核管理入口：`!usable` → 整模块拦截（文案分未开通 / 已停用）
- 依赖外审模板：演示字段 `requiresExternalAudit=true` 且 `!usable` → 不可选
- 模式三 / 不依赖外审：不受外审门禁
- 橙色虚线跨泳道＝状态生效到运行时，不是又一次配置写入

## 图 2 · 启停与编辑判定

### 2A 模板能否启用

```
请求启用报送模板
  ├─ 缺打分或缺流程？ ──是→ 拦截（提示缺哪一项）
  └─ 否
       ├─ 关联流程为模式一/二，且未开通外审？ ──是→ 拦截启用（不解绑、不自动改停用）
       └─ 否 → 允许启用
```

- 继承模板与自定义模板同一套判定
- 已开通但客户停用外审：配置侧不拦截启用；仅 PC/H5 选用拦截

### 2B 流程 / 打分能否启停

```
请求启用/停用 流程或打分
  ├─ isDefault=true？ ──是→ 禁止启停（全局与机构均置灰）
  └─ 否（自定义）
       ├─ 启用？
       │    ├─ 流程且模式一/二且未开通外审？ ──是→ 禁止启用
       │    └─ 否 → 允许启用
       └─ 停用？
            ├─ 打分且启用组只剩 1 组？ ──是→ 禁止停用
            ├─ 存在关联报送模板？ ──是→ 确认后：解绑 + 停用关联模板 + 停用本项
            └─ 否 → 仅停用本项
```

- 停用外审不走流程/打分级联

### 2C 编辑 / 删除能否执行

```
请求编辑或删除
  ├─ isDefault（机构）？ ──是→ 禁止
  ├─ isDefault（全局流程/打分）？ ──是→ 禁止
  └─ 自定义 / 允许的全局项
       ├─ 删除且存在引用？ ──是→ 确认后删除并清理绑定
       └─ 否 → 允许
```

原型不会因删母版自动扫全机构副本级联删除。

## 规则速查

### 权限矩阵

| 配置项 | 全局 · 系统默认 | 全局 · 自定义 | 机构 · 继承项 | 机构 · 自定义项 |
| --- | --- | --- | --- | --- |
| 报送模板 | 可编辑删除启停；可配绑定 | 同左 | 不可编辑删除；可启停；绑定锁定 | 可增删改启停；可配绑定 |
| 审核流程 | 不可启停 / 编辑 / 删除 | 可增删改启停 | 不可启停 / 编辑 / 删除 | 可增删改启停；停用按级联 |
| 打分规则 | 不可启停 / 编辑 / 删除 | 可增删改启停；MT 可多组启用 | 不可启停 / 编辑 / 删除 | 可增删改启停；客户端仅一组启用 |
| 绑定关系 | 母版内维护 | 母版内维护 | 锁定 | 仅本机构，不回写母版 |

置灰原文：`系统默认审核流程不支持启停。如需调整，请新建自定义审核流程。`（打分同理）

### 外部审核两层门禁

| 层次 | 字段 | 谁写 | 配置端 | PC / H5 |
| --- | --- | --- | --- | --- |
| 开通态 | `activatedStatus` | MT | 未开通 → 硬锁模式一/二启用与关联；不解绑、不强制停用 | 入口关闭；依赖模板不可选（未开通文案） |
| 启停态 | `status` | V8 客户管理端 | 已开通但停用 → 配置不锁 | 同上拦截（已停用文案） |

| 流程模式 | 依赖外审 | 未开通·配置 | 已开通但停用·配置 | PC/H5 |
| --- | --- | --- | --- | --- |
| 模式一 adaptive | 是 | 硬锁 | 不锁 | 入口 + 依赖模板拦截 |
| 模式二 max_n | 是 | 硬锁 | 不锁 | 同左 |
| 模式三 direct | 否 | 正常 | 正常 | 不受外审门禁 |

### 删除与级联

| 场景 | 行为 |
| --- | --- |
| 全局改模板/流程/打分 | 写全局库；不覆盖已落库机构副本 |
| 全局改增值业务名称/描述 | 广播到机构 + 客户目录 |
| 机构改/删继承项或改其绑定 | 禁止 |
| 自定义流程/打分停用或删除 | 有关联模板 → 确认后解绑并停用模板 |
| MT 关闭外审开通态 | 硬锁配置；不解绑、不批量停用模板 |
| 客户停用外审 | 只影响 PC/H5；配置不锁、不级联 |

### 红线

1. 机构写穿全局母版  
2. 机构编辑/删除继承项或改其绑定  
3. 因未开通/停用外审自动解绑或批量强制停用模板  
4. 系统默认流程/打分出现可点启停  
5. 把「客户停用」画成与「MT 未开通」同一条配置硬锁

## 附录 · 相对旧 PDF 的校正要点

1. 系统默认流程/打分：全局与机构均不可启停  
2. 未开通外审：只硬拦启用/关联，不强制停用、不解绑  
3. 无「同步到已创建机构」  
4. 外审须拆开通态 / 启停态两层  
5. PC/H5 原型用演示字段 + cookie，不读配置库  
6. V8 打分同时仅一组启用；MT 可多组
